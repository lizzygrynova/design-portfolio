# Mousetrap Car Project

This project was completed for **EMEC 103: Engineering Graphics Communication** at Montana State University.

For this project, I created a mousetrap-powered car using SolidWorks and manufactured it using my engineering drawings.

## Project Files

The project PDF includes:

- Assembly drawings
- Part drawings
- Bills of materials
- Manufacturing plans
- Assembly instructions

## Skills Used

- SolidWorks
- Engineering drawings
- Dimensioning and tolerancing
- Manufacturing planning
- Prototype assembly
